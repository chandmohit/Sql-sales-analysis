SQL Sales Analysis
Project Overview
This project uses SQL to analyze sales data and find useful business insights across customers, products, categories, and regions.
I created and answered 14 business questions using SQL to understand sales performance and customer activity.

Tools Used
* SQL Server
* SQL Server Management Studio (SSMS)
* GitHub

Business Questions
The analysis covers:
* Total sales and order volume
* Sales by region
* Yearly and monthly sales
* Average order value
* Top customers by sales
* Customers with high total sales
* Top-selling products
* Sales by category
* Category sales as a percentage of total sales
* Best-performing category in each region
* Average sales by category
* Customer order activity
* Average order value by customer

SQL Skills Used
* SELECT
* WHERE
* GROUP BY
* ORDER BY
* HAVING
* SUM()
* AVG()
* COUNT()
* COUNT(DISTINCT)
* Subqueries
* CTEs
* ROW_NUMBER()
* PARTITION BY

Key Findings
* Total sales were approximately $2.26 million.
* There were 4,922 unique orders.
* The West region had the highest total sales.
* November 2018 had the highest monthly sales.
* Technology accounted for 36.58% of total sales.
* Technology was the top-selling category in each region.
* 19 customers generated more than $10,000 in sales.
* Technology had the highest average sales per row among the three categories.

What I Learned
This project gave me practice using SQL to answer business questions from a sales dataset.
I worked with basic SQL functions as well as subqueries, CTEs, and window functions. It also helped me understand how to use SQL results to look at sales performance from different business perspectives.
